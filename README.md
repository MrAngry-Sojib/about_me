# Sojib Islam — Portfolio

Static portfolio website (HTML, CSS, JavaScript). No build step.

## Publish on GitHub Pages
1. Create a new repository (e.g. `MrAngry-Sojib.github.io` or `portfolio`).
2. Upload all files from this folder (keep the `assets` folder).
3. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Your site goes live in 1–2 minutes at `https://<username>.github.io/<repo>/`.

## Update content
- Photo: replace `assets/profile.jpg`
- CV: replace `assets/Sojib-Islam-CV.pdf`
- Links/projects/skills: edit the data arrays near the bottom of `index.html`
